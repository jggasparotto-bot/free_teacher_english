# 🎨 Livro para colorir: Bíblia em Traços

| Arquivo | O que é |
|---|---|
| [`livro-para-colorir-A4.pdf`](livro-para-colorir-A4.pdf) | **O livro para imprimir** (23 páginas A4): capa colorida, "Este livro pertence a", as 20 histórias para pintar e uma página para desenhar a história favorita |
| [`modelos-coloridos-A4.pdf`](modelos-coloridos-A4.pdf) | As mesmas 20 cenas já coloridas, como modelo (para mostrar na aula ou na tela) |
| [`paginas-para-colorir/`](paginas-para-colorir/) | Cada página em PNG, para imprimir avulsa ou mandar no WhatsApp |
| [`modelos-coloridos/`](modelos-coloridos/) | Cada modelo colorido em JPG |
| [`instagram/`](instagram/) | As páginas de pintar no formato de post do Instagram (1080×1350), para postar uma por semana, junto com o episódio |

**Para imprimir:** papel A4, "ajustar à página", preto e branco (as páginas de pintar são só contorno). A capa é colorida.

**Distribuição:** gratuito para famílias, escolas bíblicas e igrejas. Para vender (Hotmart, Etsy, gráfica), coloque o seu nome e o seu contato na capa antes.

Os desenhos foram feitos em código, com o mesmo motor de giz de cera dos vídeos (`../marca/arte/colorir.js`). Para gerar de novo: `sh ../marca/arte/render.sh` e o script de exportação.
